# 新手提交操作：舆情宝 LivePR

当前材料、PPT、代码和验证证据已准备好。正式提交前只做以下步骤。

## 1. 核对团队信息

打开 `舆情宝LivePR-Agent-Infra初赛方案.pptx`，重点核对第 19–22 页：

- 核对扶瑀琪、欧阳劲汝、张佳佳的姓名、公司/学校、岗位/专业和团队分工。
- 核对张佳佳的 3 项竞赛奖项、2 段实习经历和训练营证书名称。
- 核对“逃离 LEV0”获奖信息与作品链接。
- 核对第 21–22 页的 8 个项目名称、量化信息、当前进展和公开链接是否与申报表一致。
- 确认 3 位成员信息和报名资料完全一致。

保存后重新快速浏览第 2、5、7、9、11、13、17、19–22 页，确认真实事件主线、技术链路和团队项目内容无误，且文字没有溢出。

## 2. 复制作品简介

从 `作品简介-舆情宝LivePR.txt` 复制：

- 作品名称：`舆情宝 LivePR`
- 作品简介：复制“作品简介（500字以内）”下方正文，不要复制引号外说明。

## 3. 上传材料

- 必交：填写后的方案 PPT；平台接受 PDF 时可额外导出一份 PDF。
- 可选加分：`舆情宝LivePR_初赛代码包_V1_20260816.zip`。
- 若平台只允许一个压缩包，把填写后的 PPT、作品简介和代码包放进同一个 ZIP。

## 4. 提交后核对

- 在成功页确认项目名、队伍和文件版本。
- 保存成功页面截图、提交时间和版本号。
- 不要在提交后随意改队员信息。
- 队长官网提交一份；每位队员仍需在 Datawhale 夏令营页面分别打卡。

## 5. 最短演示顺序（可选视频）

1. 加载“嘉宾临时说出未授权内容”的脱敏模拟事件，展示实时转写和风险片段。
2. 展示授权/事实核验、补救策略以及澄清/安抚/转场主持台词。
3. 不带 `--approve` 运行，展示流程停在 `awaiting_approval`。
4. 带具名批准再次运行，展示 `closed`。
5. 打开 `dashboard.html`，展示台词版本、证据 ID、Agent Trace 和模拟复盘。
6. 明确说明当前是模拟数据；实时音频、活动资料 RAG 和 30 秒目标属于下一阶段验证项。
