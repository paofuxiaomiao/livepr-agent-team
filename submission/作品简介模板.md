# 作品简介模板（500 字以内）

## 填写卡

- 项目名称（约 20 字）：
- 目标用户/组织：
- 真实场景与核心痛点：
- 3 个以上 Agent 的职责：
- 核心 Skill/工具：
- 如何验证结果：
- 创新与差异化：
- 开放/复用价值：
- 当前进展：

## 可直接改写的正文骨架

【项目名称】面向【目标用户/组织】在【真实场景】中的【核心痛点】。现有流程存在【效率、成本、准确性、安全或协作问题】，单一 Agent 难以同时完成【复杂环节】。本项目以 AgentTeams 为协同基点，由【Agent A】负责【职责】、【Agent B】负责【职责】、【Agent C】负责【职责】，并通过【共享状态/上下文传递方式】完成从【输入】到【可验证输出】的端到端闭环。核心能力沉淀为【Skill 1】、【Skill 2】等可复用 Skill，接入【工具/MCP/RAG/云产品】；通过【日志、Trace、Metrics、人工复核或规则】验证结果。相较现有方案，创新点在于【1-2 个差异化优势】。计划开放【代码、Skill、接口契约、示例数据或文档】，可迁移到【相邻场景】。目前已完成【原型/Baseline/架构/测试】，下一步将完成【Demo、真实接入和评测】。
