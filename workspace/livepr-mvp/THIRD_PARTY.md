# 第三方依赖与商业边界

## 当前可运行 MVP

- Python 3 标准库：不随仓库再分发。
- 无 pip、npm 或系统级第三方运行时依赖。
- 无外部模型调用、商业 API、账号、Token 或 API Key。
- 模拟事件均为原创虚构数据。

## 可选 AgentTeams 部署

- AgentTeams：https://github.com/agentscope-ai/AgentTeams
- 其许可证和依赖以实际安装版本仓库为准。
- LLM、Embedding、Matrix、Nacos、Higress 或云服务的许可、费用和数据处理条款由部署者单独确认。

## 不进入开源仓库

- 真实活动评论、手机号、用户账号或其他个人信息。
- 商业平台私有 SDK、密钥、Token 和接口响应原文。
- 未获授权的品牌素材、主持稿和活动事实库。
